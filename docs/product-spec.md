# Tallynote — 產品決策：最優解、離線、功能唔互撞

> 2026-10-30。呢份係決策，唔係 brainstorm。下面每一條都可以直接寫成測試。

---

## 0. 三條硬原則

1. **離線即正確。** 冇網絡只可以令「匯率變舊」，唔可以令任何計算變錯或者變慢。
2. **一個意思，一個觸發器。** 同一個字唔可以同時代表兩件事；撞就用較長、較明確嗰個，另一個讓路。
3. **寧可唔答，唔好答錯。** 解析唔到就留白。錯答案嘅代價高過冇答案。

（第 3 條已經有實例：大寫 `X` 唔當乘號，`4300 X 30%` 寧可冇答案。）

---

## 1. 觸發器所有權表（One meaning, one trigger）

呢張表就係「唔互撞」嘅法律。**同一行右邊只可以有一個主人。**

| 觸發器 | 主人 | 例子 |
|---|---|---|
| `#` 開頭（行首） | 註釋／標題 | `# 餐飲` |
| `#tag`（行尾） | 標籤 | `午餐 120 #food` |
| `name = expr` | 變數宣告 | `rent = 2500` |
| `total of #tag` / `sum of #tag` | 標籤小計 | `total of #food` |
| 全行只有 `sum｜total｜average｜avg｜count｜min｜max` | 區段聚合（本節） | `sum` |
| 全行只有 `grand total｜合共｜總共｜總計｜總和｜加埋｜全部` | 全表總計（上面所有答案，按單位分組） | `合共` |
| `A is to B as C is to what` | 比例（rule of three） | `9 is to 16 as 27 is to what` |
| `if … then … else` | 條件 | `if 5 > 3 then 10 else 20` |
| `X% off Y` | 折扣 | `25% off 159.99` |
| `X is what % of Y` | 百分比反問 | `20 is what % of 80` |
| `X% of what is Y` | 百分比反問 | `5% of what is 150` |
| `compound interest P at R% for N` | 複利 | `compound interest 5000 at 7.5% for 3 years` |
| `days between A and B` | 日距 | `days between 2026-01-01 and 2026-10-30` |
| `X in｜to｜as <已知單位>` | 換算 | `100 USD in HKD` |
| `x`（細楷，夾在兩個操作數之間） | 乘 | `4300 x 30%` |
| 中文 `加｜減｜乘｜除`（可帶「以」「上」「去」） | 四則 | `30乘3` |
| `+ - * / ^ %` `(` `)` | 四則 | `2(3+4)` |
| 內建函數名 + `(` 或空格 | 函數 | `round 3.14159 2` |
| 英文日期字（today / March 12 / 3pm） | 日期 | `today + 2 weeks` |
| 已知單位字（kg / 公斤 / km） | 單位 | `5 kg` |
| 幣別碼或符號 | 貨幣 | `$20`、`100 USD` |
| 數字後面嘅未知名詞 | 動態單位 | `2 apples` |

**由呢張表直接得出嘅三條裁決：**

- `total` 作為變數名 **唔可以** 同聚合並存。裁決：如果你寫過 `total = 300`，之後 `total` 一律當變數；冇宣告過先當聚合。**用戶定義永遠贏內建。**
- `X`（大楷）冇主人 → 一律當普通字，唔計數。
- `in` / `to` / `as` 只有右邊接得上已知單位或幣別先當換算，否則當普通字（`3 in stock` 唔會亂換算）。

## 2. 解析優先次序（Ladder）

由高到低，**高層一定要「完整食晒成行」先算贏**，食唔晒就跌落下一層，唔准一半半。

```
1. 註釋 / 標題 / 空行
2. 變數宣告            name = expr
3. 顯式呼叫            func(...)  括號係最強意圖
4. 顯式換算            X in <unit>
5. 長短語              rule of three → if/then → % off → % 反問 → 複利 → 日距
6. 全行單詞聚合        sum / average / count ...
7. 標籤小計            total of #tag
8. 日期短語            整行可解成日期／時區
9. 一般表達式          lexer → parser → evaluator
10. 讀過前文散文       只可以跳過「純散文前綴」（冇數字、冇運算符）
11. 單一數字            `午餐 120`
12. 留白
```

第 10 層嘅限制就係防「靜靜答錯」嘅閘：一旦前綴出現數字或運算符就即刻停，所以 `4300 X 30%` 唔會掉到第 11 層吐個 `30%` 出嚟。

## 3. 功能分層與預算（防「唔重要嘅沖走重要嘅」）

### 預算規則
- **主介面動作上限 6 個**（新 sheet、收合側欄、隱藏答案、主題、匯率、指令板）。
- 其他所有功能一律入 `⌘K` 指令板（離線、模糊搜尋、純鍵盤）。
- 任何新功能要**先證明有一句真實用戶句**會用到，否則唔入 Core。

### Core（永遠在，唔准被擠走）
行式即時計算 · 變數 · 引用（`prev` / `line N`）· 四則與括號 · 百分比三式 · 單位換算 · 貨幣（含離線快取）· 日期加減 · 聚合 · 標籤小計 · 註釋標題 · 多 sheet · 自動儲存 · 離線。

### Enhanced（同一套輸入語言，加力量）
步驟解釋 · 反問解未知數（`? × 30% = 1290`）· 拖拉試算 · 中文 L2 短語（打八折／加一成／相差）· 函數擴充 · 匯出 Markdown/CSV。

### Lab（預設關閉，`⌘K` 開啟）
表格化／按 tag 分組 · 場景對比（what-if）· 自訂單位 · 匯出 PDF · AI 解釋（唯一會用網絡嘅功能，永遠要手動按）。

**Lab 唔准搶 Core 嘅觸發器，唔准改 Core 答案嘅格式。** 呢條就係「唔會被洗走」嘅保證。

## 4. 離線契約

| 項目 | 離線行為 |
|---|---|
| 計算 | 100% 本地，零網絡請求 |
| 單位表 | 內建（~150 個），開機即用 |
| 時區 | `timezone` 套件內嵌 tzdata（~400KB），唔靠系統 |
| 匯率 | 內建 fallback 表 → 上次快取 → 每日更新；狀態列顯示日期 |
| 匯率過期 | 超過 7 日只加一個淡點提示，**唔會令行變錯誤** |
| 儲存 | 本地 JSON，唔需要帳號，唔需要雲 |
| 字體 | 打包或用系統字，唔 fetch Google Fonts |
| AI | 只可以係手動動作，唔可以喺計算路徑上 |

判斷標準：**飛航模式開住，開 app → 打得入、計得出、存得到**，就算合格。

## 5. 防撞機制（可執行，唔係口號）

1. **Trigger registry**：把第 1 節嗰張表變成程式內一個 `const` 表，每一行標記層級。
2. **撞名測試**：一個 unit test 掃描 registry，任何兩個功能主張同一個觸發器 → 測試紅。呢個係將來加功能時唯一嘅剎車。
3. **`explain()` 顯示邊條規則中**：點答案 → 展開步驟，第一行寫「用咗 `<規則>`」。功能打架時，用戶一眼睇到係邊個贏，唔使猜。
4. **Golden tests 每加一規則加三條**：正常、邊界、應該唔觸發。

---

## 6. 明確唔做

- AI 自動判斷單位或語意（不可預測、要網絡、寫唔到測試）
- 全自然語言數學（覆蓋率低、期望落差大）
- 雲端同步／帳號（同離線原則衝突，而且用戶冇要求）
- 自動幫你揀單位（5 kg 定 5 lb 差一倍，猜錯代價太高）
- 超過 6 個主介面動作

## 7. 路線

**v0.2 — 把「解釋得到」做實**
步驟解釋（含短語層）· trigger registry + 撞名測試 · 匯率過期淡點 · 第 2 節 ladder 寫成程式碼註釋與測試。

**v0.3 — 把「問得到」做實**
反問解未知數 · 中文 L2 短語（打八折／加一成／相差／佔幾多 %）· 拖拉試算。

**v0.4 — 把「用得長遠」做實**
匯出 Markdown/CSV · 按 tag 分組 · 場景對比 · `⌘K` 指令板。

每一步完成都要滿足：`flutter analyze` 零問題、全部 tests 綠、四個平台 CI 綠、飛航模式實測過。
